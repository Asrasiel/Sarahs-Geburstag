# Überraschungs-Bild

Leg hier ein Bild mit genau diesem Dateinamen ab:

```
reveal.jpg
```

Es wird automatisch auf der Seite angezeigt, sobald der Countdown am 23.09.2026 abgelaufen ist – vorher bleibt es unsichtbar (die Seite blendet es aus, falls die Datei fehlt).

Andere Formate gehen auch, dann in `index.html` bei `id="reveal-image"` den Dateinamen entsprechend anpassen (z. B. `reveal.png`).
